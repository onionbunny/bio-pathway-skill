# 生物实体命名与消歧规则（本 Skill 强制约定）

目的：避免同名异义、异名同义、基因/蛋白混用。每条实体在 IR 中必须带 `kind`、`sources`，权威 ID 尽量带 `external_ids`。

## 1. 基因与蛋白的书写区分

| 对象 | 人（Homo sapiens） | 小鼠/大鼠（mouse/rat） | 排版 |
|---|---|---|---|
| 基因 / mRNA 符号 | 全大写拉丁字母+阿拉伯数字，如 `TP53`、`BRCA1`、`IL6` | 仅首字母大写，如 `Trp53`、`Brca1`、`Il6` | 斜体（IR 中 `italic: true`） |
| 蛋白 | 全大写，如 TP53、IL6 | 全大写，如 TRP53、IL6 | 正体（`italic: false`） |
| 蛋白全称 | tumor protein P53，正体 | 同左 | 正体 |

- 基因与蛋白即使字符串相同，也必须用 `kind` 与 `italic` 区分，禁止把“基因名”节点画成蛋白节点。
- 基因符号不含希腊字母；蛋白名中的希腊字母保留（如 TNF-α、IFN-γ）。
- 酵母/细菌基因通常全小写斜体（如 `lacZ` 按物种规范处理），蛋白首字母大写正体。无法确定物种时在 `uncertainty` 标注，不得猜测。

## 2. 物种前缀与权威命名源

- 权威库优先级：人基因 HGNC/NCBI Gene；小鼠 MGI；蛋白 UniProt；复合物/通路 Reactome、KEGG（仅用于命名核对，不用于补造机制）。
- 跨物种讨论时加物种前缀或在 `organism` 字段统一声明，前缀写法采用物种缩写加点（如 `H. sapiens TP53`、`M. musculus Trp53`），不要自造前缀。
- `external_ids` 示例：`{"db":"HGNC","id":"HGNC:11998","source":"S1"}`；来源缺失则不填，禁止编造 ID。

## 3. 同义名、旧名与家族成员

- 材料中出现的别名、旧名、缩写全部进 `synonyms`，显示标签 `label` 采用权威名；必要时在 `note` 写“旧称 XXX”。
- 同名异义（如不同物种/不同家族的缩写相同）必须拆成两个实体，并在 `note` 说明区分依据。
- 家族成员（如 STAT1/STAT3、MAPK1/MAPK3）按具体成员分别建实体；只有材料明确泛指家族时才建家族级实体，`kind` 用 `protein` 并在 `note` 标注“家族泛指”。
- 复合物（如 NF-κB 二聚体、mTORC1）建 `kind: complex` 实体，组件在 `note` 或来源中列出；不要把复合物与其亚基画成同一个节点。

## 4. 数据数值的标注纪律

- 图上出现的每个数值（fold change、p 值、置信度、表达量、时间点）必须在实体或边的 `data` 中登记，并带 `source`（指向 sources 中的页/表/图）。
- 材料没有的数值一律不写；显著性星号、阈值线同样需要来源。
- 证据强度只用四档：`supports`（证据支持）、`partially_supports`（部分支持）、`conflicting`（证据不一致）、`unverified`（待检验）。

## 5. 中文材料处理

- 中文实体名先归一到权威英文/拉丁符号再入 IR，中文译名放 `synonyms`（如“肿瘤坏死因子 α”→ 标签 TNF-α，synonyms 含中文名）。
- 图面语言跟随 task.md 要求；未指定时双语标签可写作“权威符号（中文译名）”，但不得改变斜体规则。
